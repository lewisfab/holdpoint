# Holdpoint

**Offline BDC reticle holds, bullet drop and wind for your riflescope (Android).**

<br clear="left">

Pick your scope and load, set your zero, and Holdpoint draws your reticle with the distance each circle, dot or hash
mark covers at your current magnification.

- Reticle view with the distance for every aim point, at any magnification
- Expanded BDC circle holds (top, center and bottom of each circle)
- Wind holds on the reticle, with a clock or compass wind dial
- Ballistics table: path, elevation in clicks/MOA/mils, drift, velocity, energy, time of flight
- Compare up to three loads on a trajectory graph
- Field chart: every aim point at every power
- About 2,400 factory loads from major ammunition makers, or enter your own (G1 or G7 BC)
- Temperature, altitude, pressure, humidity and shot angle
- Save a setup for each rifle
- Works completely offline: no internet permission, no account, no ads, no data collected

## Download

Get the APK from the **[latest release](https://github.com/lewisfab/holdpoint/releases/latest)**.
Requires Android 8.0 or newer.

1. Open the `.apk` file on your phone.
2. If Android asks, allow your browser or file manager to install unknown apps.
3. Tap **Install**.

To get updates automatically, add this repository's URL to [Obtainium](https://github.com/ImranR98/Obtainium).

**Verify the download (optional).** Every Holdpoint release is signed with the same key. Its SHA-256 certificate
fingerprint is:
